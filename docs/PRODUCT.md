# Product positioning

## Chosen wedge

**Primary:** Consumer **offer stress-test** for Jabodetabek job candidates who have an office location (and usually a salary) in hand.

**Not chosen as primary:** B2B office-impact analytics for HR/facilities. That remains a later monetization path once corridor accuracy and consumer usage prove out.

| Dimension | Decision |
|---|---|
| Geography | Jabodetabek corridors (not DKI-only): SCBD/Sudirman, Kuningan, BSD × feeder homes along KRL/MRT |
| Persona | Candidate with an offer (or late-stage interview) who must decide accept / negotiate hybrid / move |
| Decision moment | Offer received → start date within ~30–90 days |
| Core UX | Map pins + structured scenarios (home options × modes × hybrid days) |
| LLM role | Deferred; report is generated from computed tables only |
| Housing | User-entered monthly rent or preset area rent bands — no listings scrape |
| Accuracy framing | P50 / P80 peak commute bands + rain/peak caveats; motorcycle & ojek first-class |
| Payer (near-term) | Free tool; distribution via shareable decision brief |
| Payer (later) | Employers (office impact) or job/property platform embeds |

## Why this wedge

1. Deadline and money on the line → higher intent than casual browsing.
2. Inputs are concrete (office pin, salary, hybrid days, current/candidate homes).
3. Success is observable: negotiate WFH, change home shortlist, accept/reject differently.
4. Avoids B2B sales cycle before product truth exists.

## Explicit non-goals (MVP)

- Free-form AI chat agent
- Citywide multimodal routing graph
- Housing marketplace / scraped listings
- Accounts, teams, or employer dashboards
- Guaranteed door-to-door ETAs competitive with Google/Grab

## Success metric

A user changes at least one of: home shortlist, hybrid negotiation ask, or offer accept/reject rationale — not PDF download count alone.
